# line-messages：LINEで別送するメッセージ（スマホ版マニュアルの付録）

- 用途：スマホ版マニュアル（manual-sp.md）の「LINEで届く4つのメッセージ」で、「このマニュアルを受け取ったLINEに、別のメッセージで4つ送っています」と案内している4通（【1】〜【4】）と、その前に送るPDFのリンクのメッセージ（【0】）。
- 送り方：【0】PDFのリンクのメッセージ → メッセージ1 → 2 → 3 → 4 の順で、1通ずつ別のメッセージとして送る（まとめて1通にしない）。
- 貼り方：下の「```」の中だけを、そのまま1通として貼る。改行もそのまま。絵文字は使っていない。
- 【0】の「［PDFのリンク］」は、実際のPDFのURLに差し替える（その1行だけ）。質問の窓口の案内は、マニュアル本文の「困ったときの窓口」の1回だけにするため、【0】には入れていない。
- 1行目の【1】〜【4】は前置き（どのメモのどこに貼るかの目印）。LINEの長押しコピーはメッセージ全体が入るので、AIに渡っても困らない形にしてある。マニュアル本文で「そのまま残しておいて大丈夫」と案内している。
- メッセージ1〜3は、PDFの本文に載せたひな形と文字を同じにしてある。メッセージ4は、本文の4か所（1章 仕事選びのメモ／2章 担当表／5章 うちのAIにやらせないこと／6章 1か月後の振り返りメモ）を1通にまとめたもの。仕事選びと振り返りの行は本文と同じ文字。担当表は本文では記入例（架空）なので、ここでは項目だけ残して（　）にしてある。やらせないことは、本文の箇条書きを「・」にして、（御社で足すこと）を1行足してある。どちらかを直すときは、もう一方も直すこと。

---

## 【0】PDFのリンクを送るメッセージ

```
錦織です。noteでご案内した「工務店向け AI社員の作り方マニュアル」をお送りします。
［PDFのリンク］
このあと、マニュアルで使うひな形を4つ、別々のメッセージでお送りします（【1】〜【4】）。
長押しでコピーして、メモアプリに貼って使います。使い方はマニュアルに書いてありますので、消さずに残しておいてください。
```

## メッセージ1：AIへの頼み方の文例

```
【1】AIへの頼み方の文例（担当の名前の下に貼ります）
以下は、当社の「（担当の名前）」のルールです。このルールに沿って、（仕事の内容）の下書きを作ってください。
条件：（文字数・使う場面など）
今回の材料：（例：見学会なら、どんな家か・見てほしいところ・誰に来てほしいか。日時・会場は入れず、あとで人が書き入れる）
材料に書いていないことは、書かないでください。分からないところがあれば、作る前に質問してください。
――ここから下が、ルールシートと直しメモです――
```

## メッセージ2：ルールシートのひな形

```
【2】ルールシート（文例の下に貼ります）
担当の名前：（担当表と同じ名前。担当表をまだ書いていなければ、ここで名前を付けます）
この仕事の目的：（誰に、何を届けるための仕事か。1文で）
読む人：（どんなお客さんに向けて書くか）
大事にしている考え方：
①（　）
②（　）
③（　）
言い方のルール：（使う言葉・使わない言葉、呼び方、です・ます など）
書かないこと：（大げさな言い方、他社の悪口、決まっていない約束 など）
出来上がりの形：（文字数の目安、見出しの有無、最後の一文）
お手本：（社長が「これはいい」と思う過去の文面。お客さんの名前・金額・住所・電話番号などは消してから貼る）
```

## メッセージ3：直しメモのひな形

```
【3】直しメモ（ルールシートの下に貼ります）
（日付）
直したこと：（AIの下書き）→（どう直したか）
次からのルール：（1行で）
```

```

候補3：（仕事）　当てはまる基準：（1〜5の番号）
最初の1人に任せる仕事：（　）

任せる仕事：（　）
頼む人：（　）
下書きを確認して直す人：（　）
出す人（送信・投稿・印刷）：（　）
任せないこと：（　）

■うちのAIにやらせないこと

## 配信前に人が確かめること

- [ ] エルメで、登録後に【0】PDFのリンクのメッセージ → メッセージ1 → 2 → 3 → 4 の順で届く設定になっているか（テスト登録で1回確かめる）。あいさつの文面なども同時に送るなら、1回に送れる吹き出しの数の上限に収まるか。
- [ ] 【0】の「［PDFのリンク］」が、実際のPDFのURLに差し替わっているか。
- [ ] スマホのLINEで各メッセージを長押し →「コピー」→ メモアプリに貼ったとき、改行と（　）・【　】・「――」・「■」・「・」が崩れずに貼れるか（iPhone・Androidで1台ずつ見られると安心）。
- [ ] メッセージ1〜3の文字が、manual-sp.md の本文のひな形と同じか。メッセージ4の仕事選び・振り返りの行が、本文の1章・6章と同じか。
