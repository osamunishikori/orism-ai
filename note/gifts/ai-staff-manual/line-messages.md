# line-messages：LINEで別送するメッセージ（スマホ版マニュアルの付録）

- 用途：スマホ版マニュアル（manual-sp.md）の3章・4章で「同じものを、このLINEに別のメッセージで送っています」と案内している3通。
- 送り方：PDFのリンクのあとに、メッセージ1 → 2 → 3 の順で、1通ずつ別のメッセージとして送る（3通をまとめて1通にしない）。
- 貼り方：下の「```」の中だけを、そのまま1通として貼る。改行もそのまま。絵文字は使っていない。
- 1行目の【1】〜【3】は前置き（メモのどこに貼るかの目印）。LINEの長押しコピーはメッセージ全体が入るので、AIに渡っても困らない形にしてある。マニュアル本文で「そのまま残しておいて大丈夫」と案内している。
- PDFの本文に載せたひな形と、文字は同じにしてある。どちらかを直すときは、もう一方も直すこと。

---

## メッセージ1：AIへの頼み方の文例

```
【1】AIへの頼み方の文例（メモのいちばん上に貼ります）
以下は、当社の「（担当の名前）」のルールです。このルールに沿って、（仕事の内容）の下書きを作ってください。
条件：（文字数・使う場面など）
今回の材料：（例：見学会なら、どんな家か・見てほしいところ・誰に来てほしいか。日時・会場は入れず、あとで人が書き入れる）
材料に書いていないことは、書かないでください。分からないところがあれば、作る前に質問してください。
――ここから下が、ルールシートと直しメモです――
```

## メッセージ2：ルールシートのひな形

```
【2】ルールシート（文例の下に貼ります）
担当の名前：（担当表と同じ名前。担当表をまだ書いていなければ、ここで名前を付けます）
この仕事の目的：（誰に、何を届けるための仕事か。1文で）
読む人：（どんなお客さんに向けて書くか）
大事にしている考え方：
①（　）
②（　）
③（　）
言い方のルール：（使う言葉・使わない言葉、呼び方、です・ます など）
書かないこと：（大げさな言い方、他社の悪口、決まっていない約束 など）
出来上がりの形：（文字数の目安、見出しの有無、最後の一文）
お手本：（社長が「これはいい」と思う過去の文面）
```

## メッセージ3：直しメモのひな形

```
【3】直しメモ（ルールシートの下に貼ります）
（日付）
直したこと：（AIの下書き）→（どう直したか）
次からのルール：（1行で）
```

- [ ] メッセージ1〜3の文字が、manual-sp.md の本文のひな形と同じか。
