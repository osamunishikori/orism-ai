## 2. ページ数：10ページ（brief の「6〜8ページ程度」を2ページ超えた）

| ページ | 中身 |
|---|---|
| 1 | 表紙（藍地） |
| 2 | はじめに |
| 3 | 1章（チェック表・「最初の1人に任せる仕事」欄まで1ページ） |
| 4 | 2章（担当表） |
| 5〜6 | 3章（5＝ルールシートまで／6＝紙からAIへ・文例・最初の1回の流れ） |
| 7 | 4章（直しメモ） |
| 8 | 5章（やらせないことリスト） |
| 9 | 6章（週ごとの進め方・振り返り表） |
| 10 | おわりに・困ったときの窓口 |

- **8ページに収まらない理由**：「# の章ごとに改ページ」だと、表紙＋8章で最低9ページ。3章は文章とルールシート（書き込み欄）だけで1ページを超えるので、10ページが下限。
- 改ページを外して詰めても9ページ（試算。表を途中で切らない条件のため）。8ページにするには、文字を9pt未満にするか書き込み欄を低くするしかなく、読みやすさ・書きやすさを優先して見送った。
- 中身は削っていない。2・おわりにのページは下半分が空く（章ごとの改ページのため）。
- 詰めた内容：余白を狭く（上11／左右13／下13mm）、本文9.5pt・行間1.55、表8.8pt。

8ページ以内が必須の場合：
- 2章やおわりにだけ前の章に続けても、1章・6章のページがすでに埋まっているので10ページのまま変わらない。
- 8ページにするには、文字を9pt未満にする・書き込み欄を低くする・中身を減らす、のどれかが要る。デザイン担当としては、このまま10ページで出すことをすすめる（印刷して書き込む用途を優先）。判断は錦織さん。

## 3. 組み方

- 配色：表紙＝藍 #17324D 地に生成り #FAF6EE の文字、副題と飾りの線だけ山吹 #F2A93B。本文ページ＝白地に藍の文字、表の見出しと文例の枠の地＝生成り、山吹は見出しの縦線・章番号の丸・書き込み欄の上線だけ（山吹は文字色に使わない）。
- フォント：Google Fonts「Noto Sans JP」400/500/700/900（SIL Open Font License）。読めないときは Hiragino → 游ゴシック → メイリオ → IPAexゴシック → IPAゴシック。
- 文例（review 3回目 C1）：「>」の5行を1行ずつ別の行に組み、行の間に点線。最後の「――ここから下が、ルールシートと直しメモです――」も独立した1行（太字）。（　）の中は書き換える所なので山吹の下線。
- 書き込み欄（印刷して手書き）：山吹の上線で目印。行の高さ＝チェック表13mm／最初の1人の欄14mm／担当表15mm／ルールシート16.5mm（①②③は1行8mm×3）／直しメモ9mm×8行／やらせないことリスト10.5mm／振り返り表11mm。振り返り表の「行」「個」は右寄せ（左に数字を書く）、「ある・少しある・ない」「続ける・形を変える・やめる」は○で囲めるよう間をあけた。
- 記入例（架空）の行は生成り地で、書き込む行と見分けられるようにした。
- 1章の「最初の1人に任せる仕事」（1列だけの表）は、見出しを左・書く欄を右の1行にした（文字は同じ）。
- 表・文例の枠・「## 見出し＋直後のまとまり」はページの途中で切れないよう指定（break-inside: avoid）。

## 5. 作り直し手順

文章を直すときは **manual.md だけ** を直し、次の1行で html と pdf を作り直す（manual.html を手で直しても、次に作り直すと上書きされる）。

```
node /home/user/orism-ai/note/gifts/ai-staff-manual/make-pdf.js
```

- 必要なもの：node と Playwright（`require('playwright')` が使えること）、Google Fonts に届くネット接続。
- 出力の最後に `Noto Sans JP loaded: true` と出れば、フォントが読めている。
- 作り直したら `pdfinfo manual.pdf` でページ数を見て、各ページを画像にして目視する（例：`pdftoppm -r 80 -png manual.pdf /tmp/check/p`）。文章が増えると、章が次のページにはみ出してページ数が増えることがある。
- 行の高さ・文字の大きさは make-pdf.js の `CSS` の中（`table.tpl-…` が書き込み欄、`body` が本文の文字の大きさ）。
- Playwright が無い環境：manual.html を Chrome で開き、印刷 → 送信先「PDFに保存」、用紙 A4・縦、余白「デフォルト」、「背景のグラフィック」にチェックを入れて保存（ページ番号は CSS で入るので、Chrome の「ヘッダーとフッター」は外す）。

- 改ページは表紙のあとと「## 1.」〜「## 6.」の前だけ（7か所）。それ以外の ## は前に続けて流し込んだ（書き手メモの「45画面」にはしていない）。

### 7-3. 組み方

- 配色（見出し画像とそろえた）：表紙＝黒板 #23453a の地にチョーク #f1efe4 の文字。本文ページ＝白地に濃い文字 #1f2a26。差し色は黒板の緑（見出しの縦線・章見出しの帯・番号の丸・枠の線）。ひな形の枠の地と「作業がゼロに…」の囲みはチョーク色。
- 表紙：見出し画像と同じ工事黒板。チョークの罫線で「工務店向け／題名・副題／リード文／株式会社オリズム　錦織 修」の4段に区切り、下に粉受けとチョーク。新しい文言は足していない。
- フォント：表紙と章見出しは Google Fonts「Klee One」（SIL Open Font License）。本文は「Noto Sans JP」（同）。
- 章見出し（## 1.〜## 6.）は黒板色の帯に、番号とチョークの縦線（工事黒板の欄の見た目）。
- 「>」のひな形・記入例：1行ずつ別の行に組み、行の間に点線。長い行が折り返したときは2行目を1字下げて、元の改行と見分けられるようにした。
  - LINEで送る3通（【1】〜【3】で始まるもの）：緑の実線の枠。1行目の【N】…は枠の見出し帯にした。（　）の中（書き換える所）に緑の下線。
  - 仕事選びのメモ・振り返りメモ：同じ実線の枠（1行目の帯なし）。
  - 記入例（担当表・直しメモ）：点線の枠・白地で、ひな形と見分ける。書き換える所の下線は付けない。2つの記入例の間（空の「>」行）は線で区切った。
  - 「項目：」の項目名は太字の緑。
- ページの途中で切らないもの：章見出し・## 見出し（次の行と同じページ）、ひな形・記入例の枠（見出しごと）、3項目までの短い箇条書き（見出しごと）、「**1. 社長が…**」のような太字の小見出し＋説明、約5行までの短い段落、箇条書きの1項目。「今の私の答えは、こうです。」と太字の答えは同じページにそろえた。
- 長い段落は途中で切れてよい（ページ末の空きを減らすため）。

### 7-5. 作り直し手順

文章を直すときは **manual-sp.md だけ** を直し、次の1行で html と pdf を作り直す。

```
node /home/user/orism-ai/note/gifts/ai-staff-manual/make-pdf.js sp
```

- A4版は `node make-pdf.js`、両方は `node make-pdf.js all`。html だけなら末尾に `--html-only`。
- 出力に `Noto Sans JP loaded: true / Klee One loaded: true` と出れば、フォントが読めている。

- 文字の大きさ・行間・余白は make-pdf.js の `CSS_SP` の中（`@page` が余白、`body` が本文、`.copy-box` 以下がひな形の枠）。
- ひな形の本文を直したら、line-messages.md（LINEで送る3通）も同じ文字にそろえる。
- Playwright が無い環境：manual-sp.html を Chrome で開き、印刷 → 送信先「PDFに保存」、余白「なし」ではなく「デフォルト」、「背景のグラフィック」にチェック、「ヘッダーとフッター」は外す（用紙の大きさは CSS で入る）。
