# 工務店向け AI社員の作り方マニュアル

担当1人から始める、1か月の進め方

株式会社オリズム　錦織 修

> このマニュアルは、御社で最初のAI社員を1人決めて、1か月一緒に仕事をしてみるための手引きです。

---

# はじめに

こんにちは、錦織です。noteを読んで、LINEに登録してくださってありがとうございます。

このマニュアルは、記事の最後に書いた「最初の一歩」の続きです。あの3つの一歩を、手を動かせる形にしました。

記事のおさらいを、少しだけしておきます。

- **AI社員**とは、担当とルールを決めて仕事を任せるAIのことです。
- 作り方は、新人の育て方と同じです。担当を決めて、ルールを渡して、注意したことを覚えてもらいます。
- いきなり何人もいりません。まずは1人からです。

## このマニュアルでやること

| | やること | 使う型 |
|---|---|---|
| 1 | 最初の1人に任せる仕事を選ぶ | 仕事選びのチェック表 |
| 2 | 担当を決める | 担当表 |
| 3 | ルールを紙1枚にまとめる | ルールシート |
| 4 | 直したところを貯める | 直しメモ |
| 5 | AIにやらせないことを決める | やらせないことリスト |
| 6 | 1か月、週ごとに進める | 週ごとの進め方・振り返り表 |

## 用意するもの

- パソコン（貼り付けや書き足しをするので、パソコンが楽です）
- ClaudeのようなAIのサービス。費用は月数千円からです。料金は変わることがあるので、申し込む前に公式の料金ページで確かめてください。
- このマニュアルを印刷したもの。書き込んで使います。
- **直す時間。** ここは社長から出ます。先にカレンダーに入れておいてください。

## 空欄があっても大丈夫です

表は、全部埋まらなくても大丈夫です。埋まらない欄があれば、それは「まだ言葉になっていないこと」が見つかったということです。

そこが、この1か月でいちばんの収穫になるかもわからないですね。

# 1. 最初の1人に任せる仕事を選ぶ

最初の1人に何を任せるかで、続けやすさがだいぶ変わります。迷ったら、次の5つの基準で考えてみてください。

## 選ぶときの5つの基準

1. **社長が毎回手を入れている仕事**
   社員さんが書いたものを、結局社長が直している。そういう仕事には、社長の考え方がいちばん表に出ます。AIに渡す材料も、社長の頭の中にあります。
2. **文章で終わる仕事**
   AIが作るのは下書きまで。出すのは人、と線を引きやすい仕事が向いています。
3. **くり返し出てくる仕事**
   年に1回の仕事だと、直したところが次に生きるまでに時間がかかります。
4. **お客さんの名前・金額・住所がなくても下書きできる仕事**
   入れてはいけない情報を、最初から使わずに済みます。
5. **間違っても、出す前に社長が止められる仕事**
   送信や契約にそのままつながる仕事は、最初は避けます。

## 工務店での例

ここに挙げるのは、あくまで例です。オリズムで効果を確かめたものではありません。御社の仕事に置き換えて考えてみてください。

| 仕事の例 | 向いている理由 | 気をつけること |
|---|---|---|
| 見学会・イベントの告知文 | くり返し出てくる。会社の考え方が出る | 日時・場所は人が確かめる |
| OB施主さん向けのお便りの下書き | テーマが変わっても、言い方のルールは同じ | お客さんの名前は入れない |
| お問い合わせへの返信の下書き | 社長が毎回直していることが多い | 名前を伏せて頼む。送るのは人 |
| 求人の文面 | 会社が大事にしていることを言葉にする練習になる | 給与などの条件は人が書く |
| SNS投稿の文面 | 数が多く、言い方がぶれやすい | 投稿するのは人 |

逆に、最初は避けたいのはこんな仕事です。

- 見積もりや契約書など、金額が決まるもの
- クレームへの最終の返事
- 法律や補助金の判断が入るもの

どれも、AIの下書きより先に、人の判断が要る仕事です。

候補を3つまで書いて、当てはまるものに○をつけてください。○がいちばん多いものが、最初の1人の候補です。

| 候補の仕事 | ①社長が毎回直している | ②文章で終わる | ③くり返し出る | ④名前・金額なしで書ける | ⑤出す前に止められる |

# 2. 担当表を作る

新人が入ったとき、最初に「あなたの担当はこれね」と伝えますよね。AI社員も同じです。

何を任せて、どこから先は人がやるのか。ここを先に1枚にしておきます。

## 担当表

| 項目 | 記入例（架空） | 御社の場合 |
|---|---|---|
| 担当の名前 | 見学会の告知係 | |
| 任せる仕事 | 見学会の告知文の下書き（チラシ用・SNS用） | |
| 頼む人 | 社長 | |
| 下書きを確認して直す人 | 社長 | |
| 出す人（送信・投稿・印刷） | 事務の担当者 | |
| 任せないこと | 日時・場所の確定、投稿、お客さんの名前を書くこと | |
| 頼むタイミング | 見学会が決まったとき | |

「確認して直す人」は、最初は社長にしておくのがいいと思います。直したところに、社長の考え方が入るからです。

# 3. ルールシートを書く（紙1枚）

ルールシートは、新人に渡すマニュアルとチェックリストのようなものです。AIは毎回、これを読んでから仕事を始めます。

## 書く前に知っておいてほしいこと

最初からうまく書けなくても大丈夫です。私の話し方のルールも、AIに「そこは違う」と直しながら、少しずつ言葉になっていきました。

完璧な1枚より、まず書き始めた1枚の方が先に進みます。迷ったら、新人に口で説明するつもりで、話した言葉をそのまま書いてみてください。

参考までに、私の話し方のルールの一部です。

- 相手の話をまず「なるほど」と受け止めてから、自分の考えを言う
- 否定から入らない
- 「〜かもわからないですけど」と、余白を残す
- 呼び方は「御社」「お客さん」

これくらいの短さで十分です。

## ルールシート

| 項目 | 書くこと | 御社の場合 |
|---|---|---|
| 担当の名前 | 担当表と同じ名前 | |
| この仕事の目的 | 誰に、何を届けるための仕事か（1文で） | |
| 読む人 | どんなお客さんに向けて書くか | |
| 大事にしている考え方 | 3つまで | ①<br>②<br>③ |
| 言い方のルール | 使う言葉・使わない言葉、呼び方、です・ます など | |
| 書かないこと | 大げさな言い方、他社の悪口、決まっていない約束 など | |
| 出来上がりの形 | 文字数の目安、見出しの有無、最後の一文 | |
| お手本 | 社長が「これはいい」と思う過去の文面（名前・金額は消す） | |

## AIへの頼み方（そのまま使える文例）

AIの画面を開き、質問を打ち込む欄に、次の文とルールシートを貼り付けます。

> 以下は、当社の「（担当の名前）」のルールです。このルールに沿って、（仕事の内容）の下書きを作ってください。
> 条件：（文字数・使う場面など）
> 分からないところがあれば、作る前に質問してください。
> ――（ここにルールシートと直しメモを貼る）――

初めのうちは、毎回貼るやり方で十分です。

慣れてきたら、毎回読ませる指示を保存しておく機能（Claudeの「プロジェクト」など）を使う手もあります。そこにルールシートを置いておけば、貼る手間が減ります。

# 4. 直しメモをつける

ここが結構大事なところです。

AIの下書きを直したら、何を直したかを1行で書き残します。そして次に頼むとき、そのメモもAIに読ませます。

新人に注意したことを、本人がノートに書いておく。あれと同じです。ノートがないと、同じ注意を何度もすることになりますよね。

## 私の場合

オリズムでは2026年7月から、AIに「そこは違う」と言ったことを1行ずつ貯めてきました。いちばん多く直したのは口調でした。

AI錦織のメモは、10月末の時点で193行あります。注意されたことだけでなく、気づきも含めた行数です。

メモは月に1回整理して、重なっているものをまとめ、古くなったものは書き直します。私が確認して「これは決まりにしよう」と思ったものは、正式なルールに格上げします。8月には、11件をまとめて格上げしました。

## 直しメモ

| 日付 | 直したこと（AIの下書き → どう直したか） | 次からのルール（1行） | ルールシートへ |
|---|---|---|---|
| 記入例（架空） | 「〜させていただきます」が続いて固い → 「〜します」にした | 「させていただきます」は1回まで | □ |
| 記入例（架空） | 「ご来場お待ちしております！」が3回出てきた → 最後の1回だけ残した | 同じ呼びかけはくり返さない | □ |

## メモの使い方

- 書くのは1行で十分です。きれいに書かなくて大丈夫です。
- 次に頼むときは、ルールシートと一緒に直しメモも貼ります。
- 同じ直しが何度も出てきたら、ルールシートに格上げして「ルールシートへ」の□に印を入れます。
- 私のところでは、同じ種類の間違いが3回続いたのをきっかけに、正式なルールにしたことがあります。3回くらいを目安にしてもいいかもわからないですね。
- 月に1回、重なっているものをまとめ、古くなったものは書き直すか消します。

# 5. AIにやらせないこと

任せることと同じくらい大事なのが、やらせないことを先に決めることです。新人にも「ここから先は、必ず私に確認してね」という線を引きますよね。

オリズムでも、noteの公開、SNSへの投稿、メールやLINEの配信は、AIはしません。AIが作るのは文面までで、出すのは人間です。

## 入れない情報

AIに貼り付ける文章には、次のものを入れないでください。

- お客さんの名前
- 金額（見積もり・契約金額など）
- 住所（建築地も含めて）
- 電話番号やメールアドレスなど、個人が分かるもの

必要なときは「A様」「◯◯万円」「◯◯市」のように置き換えて頼みます。本当の名前や数字は、仕上げのときに人が書き入れます。

また、サービスによっては、入力した内容をAIの改良に使う設定になっていることがあります。始める前に、設定の画面で一度確かめておくと安心です。

## 人がやること（最終判断）

- **送信**：メール・LINE・お問い合わせへの返信
- **投稿**：SNS・ホームページ・チラシの入稿など
- **契約に関わる判断**：金額・条件・お客さんとの約束ごと
- **確認**：数字・日付・法律や補助金に関わる内容。AIは間違えることがあるので、元の資料で確かめます

# 6. 1か月の進め方

1か月で目指すのは、最初の1人が「ルールシートと直しメモを読んでから仕事を始める形」ができることです。

作業時間がどれだけ減るかは、ここでは約束できません。私自身、測っていないからです。

## 週ごとの進め方

| 週 | やること | 済んだら□ |
|---|---|---|
| 1週目<br>選ぶ・書く | 仕事選びのチェック表で1つ選ぶ／担当表を書く／ルールシートの最初の1枚を書く／やらせないことリストを決める／下の振り返り表に目を通し、1か月後に何を見るかを決めておく | □ |
| 2週目<br>頼む・直す | 実際の仕事で下書きを頼む／直したところを直しメモに1行ずつ書く | □ |
| 3週目<br>育てる | 直しメモを読み返し、何度も出てきた直しをルールシートに格上げする／書き直した1枚で、同じ種類の仕事を頼んでみる | □ |
| 4週目<br>振り返る | 振り返り表を埋める／次の1か月を「続ける・形を変える・やめる」から決める | □ |

毎週、直す時間を先にカレンダーに入れておいてください。後回しにすると、直しメモが貯まりません。

## 1か月後の振り返り表

何を見て続けるかを、始める前に決めておきます。決めておかないと、なんとなく続いて、なんとなく止まってしまうからです。

| 見ること | 記入欄 |
|---|---|
| 直しメモは何行たまったか | 行 |
| ルールシートに格上げしたルールは何個か | 個 |
| 同じ直しが減ってきた感じはあるか | ある・少しある・ない |
| 直す時間は、誰の、どの時間から出ていたか | |
| 社長の考え方で、新しく言葉になったことは何か | |
| 次の1か月 | 続ける・形を変える・やめる |

もし「やめる」と決めても、ルールシートと直しメモは手元に残ります。社長の考え方を言葉にした紙です。人の新人を迎えるときにも、使えるかもわからないですね。

## 2人目は、1人目が回ってから

いきなり何人もいりません。私も、10人のチームを作ったのは、7月からAI錦織と仕事をしてきたあとの10月末でした。

1人目のルールシートと直しメモが回り始めたら、2人目を考えるくらいで十分だと思います。

# おわりに

「それで何が楽になるの」。顧問先の社長のこの一言から、記事を書きました。

今の私の答えは、こうです。**作業がゼロになるのではなく、社長の考え方と直したところが、会社に残るようになる。**

利用料が安くても、答える・選ぶ・直す時間は社長から出ていきます。そこだけは、最初に勘定に入れておいてください。

それでも、社長が毎回口で伝えていたことが、紙に残ります。社長がその場にいないときにも届く形です。

まずは小さな一歩として、今週、チェック表に候補の仕事を3つ書いてみてください。

進めていて分からないところがあれば、このLINEにそのまま送ってください。

# 書き手メモ（PDFに入れない）

- 構成：brief の「必ず入れること」をすべて章にした（選び方の基準と例→1章／担当表→2章／ルールシート→3章／直しメモ→4章／やらせないこと→5章／週ごと→6章／LINE案内→おわりに1回）。`#` が章（改ページの目安）、`##` が節。`---` は章の区切り。
- 分量：本文は約7,000字（表を含む）。A4縦で7〜8ページの見込み。チェック表・担当表・ルールシート・直しメモは書き込み欄なので、デザインで行の高さを広めに取ってほしい。
- 確認が要る点：
  1. **費用「月数千円から」**：公開前に公式の料金ページで確認（brief どおり。記事と同じ書き方にそろえた）。
  2. **「毎回読ませる指示を保存しておく機能（Claudeの『プロジェクト』など）」**：機能名が今の画面の表記と合っているか、錦織さんか公式で確認。記事は「毎回貼る」やり方なので、本文は「慣れてきたら」の補足にとどめた。
  3. **「入力した内容をAIの改良に使う設定になっていることがある」**：一般的な注意として書いた（research の東商の指摘が下敷き。原典は未確認）。サービス名・設定名は書いていない。この一文を残すか判断を。
  4. **工務店での例（告知文・OBのお便り・返信の下書き・求人・SNS）**：research の候補から書き手が選んだもの。錦織さんが「最初に任せるならこれ」と勧めるものと合うか確認したい（壁打ちで未回答）。本文では「オリズムで効果を確かめたものではない」と明記した。
  5. **「同じ種類の間違いが3回続いたのでルールにした」**：nishikori-core §5 の実例を使った。「3回くらいを目安に」は書き手の提案なので、錦織さんの感覚と合うか確認を。
  6. **振り返り表・「続ける・形を変える・やめる」**：nishikori-core §5-4（通過基準と撤退条件を先に置く）をもとに書き手が作った型。錦織さんの実体験ではない。
  7. **記入例（担当表・直しメモ）はすべて架空**と明記した。錦織さんの実際の直しメモから、伏せて出せる例があれば差し替えたい。
  8. **最後の「このLINEに送ってください」**：質問が来たら誰がいつ返すか（錦織さんの時間の勘定）と、エルメで個別の質問を受けて返せる設定かを確認。返せない場合は文言を変える。
  9. **数字**（2026年7月開始・193行〈10月末時点、気づき含む〉・8月に11件格上げ・10人チームは10月末）は記事と同じものだけを使った。新しい数字は足していない。
  10. 表紙の「株式会社オリズム　錦織 修」の表記（スペース・肩書の有無）を確認。
- 足りなかった材料：社員さんの反応（AI社員を入れて社内でどう受け止められたか）と、note以外で錦織さんが最初に任せるなら何か。聞ければ1章の例と「おわりに」を厚くできる。
